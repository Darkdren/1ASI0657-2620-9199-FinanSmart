# FinanZen — Mobile

**Estado: pendiente de implementación.** El usuario confirmó que todavía no
existe un proyecto móvil para incorporar. Esta carpeta reserva su ubicación.

## Alcance previsto

Cliente móvil para el producto descrito en el informe: registro financiero,
presupuestos, educación y conexiones con dispositivos, según el incremento
que se implemente. El diagrama del PDF propone Flutter para iOS/Android;
todavía no hay un proyecto Flutter ni una configuración de compilación.

Los contratos REST actuales del backend son el punto inicial de integración.
La gestión de identidad y el resto de servicios siguen pendientes. El diseño
adaptable de `front` no constituye una aplicación móvil nativa.

No hay código móvil, instrucciones de compilación, APK ni publicación en tiendas.
